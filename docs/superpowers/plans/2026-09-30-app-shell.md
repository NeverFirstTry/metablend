# App Shell (Phase 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Capacitor app feels native: a bottom tab bar (Forecast · Hiking · More), safe-area layout, native share / location / haptics / Android back button, a "More" screen with settings — and the Android + iOS projects configured to run it.

**Architecture:** The app loads https://metablend.app (spec approach 1). App-only chrome is rendered by the website itself when it detects the app (`MetaBlendApp` user agent, or the `?app=1` test cookie), marking `<html data-app>` so CSS hides web-only parts. Native calls go through `lib/native.js`, which dynamic-imports the Capacitor plugin JS only inside the app (web visitors never download it). The native projects in `mobile/` carry the same plugins' native code.

**Tech Stack:** Next.js 16, Capacitor 8.5 (`@capacitor/core` incl. SystemBars, `@capacitor/app`, `@capacitor/geolocation`, `@capacitor/share`, `@capacitor/haptics`), `node --test`.

**Spec:** `docs/superpowers/specs/2026-09-30-hiking-app-design.md` (phase 3 = §5).

## Global Constraints

- Verified 2026-09-30 (Capacitor 8 docs): `server.url` loads the remote site ("intended for live reload, not for production" — accepted risk of approach 1); `appendUserAgent` appends to the WebView UA; `server.errorPath` shows a local page on load errors (no plugin access on Android); SystemBars is core and injects `--safe-area-inset-*` CSS variables on Android (`insetsHandling: "css"`), use `var(--safe-area-inset-x, env(safe-area-inset-x, 0px))`.
- Plugin JS versions in the web app and native plugins in `mobile/` must share the major version (8.x).
- Push notifications are phase 4 — the push plugin is NOT installed now (it needs Firebase config to register).
- Web visitors see no change except the new `/more` page; everything app-only is behind the app detection.
- All UI text in 5 languages via `t()`.
- This PC has no Java / Android SDK: native builds and device tests are the owner's (checklist in Task 6); everything web-side is verified with `?app=1` phone screenshots.
- Commit and push straight to `main` after each task.

## Review Focus

- Web visitor on a phone (no app) → no tab bar, footer and install button still visible. Pinned in Task 3 (screenshot without `?app=1`).
- App detected but a plugin call fails (e.g. location denied) → graceful fallback, no uncaught promise. Pinned in Task 1 (`nativePosition` returns null on rejection).
- Tab bar never covers content: last element of every page stays reachable above the bar. Pinned in Task 3 (screenshot of page bottom with `?app=1`).
- `/more` settings change language / unit / theme for the whole site (same cookies as the home page). Pinned in Task 4 (browser check).
- Android back button on the first screen → app exits instead of doing nothing. Pinned in Task 6 device checklist.

`lib/prefs.js`:
```js
// Cookie-backed preferences shared by every page (language, unit, theme,
// recent cities). readCookie is pure for tests; get/setCookie touch document.
export function readCookie(cookieString, name) {
  const m = (cookieString ?? '').match(new RegExp('(?:^|; )' + name + '=([^;]*)'))
  return m ? decodeURIComponent(m[1]) : null
}

export function getCookie(name) {
  return typeof document === 'undefined' ? null : readCookie(document.cookie, name)
}

export function setCookie(name, value, days = 365) {
  const expires = new Date(Date.now() + days * 864e5).toUTCString()
  document.cookie = `${name}=${encodeURIComponent(value)}; expires=${expires}; path=/; SameSite=Lax`
}
```

`lib/native.js`:
```js
// Native features inside the Capacitor app. Plugin JS is dynamic-imported
// only when running natively, so web visitors never download it; every
// helper falls back quietly (false / null) when a call fails.
export function isNative(win = globalThis.window) {
  return !!win?.Capacitor?.isNativePlatform?.()
}

export async function nativeShare({ title, text, url }) {
  if (!isNative()) return false
  try {
    const { Share } = await import('@capacitor/share')
    await Share.share({ title, text, url })
    return true
  } catch {
    return true // the sheet was shown and cancelled — don't fall back to copying
  }
}

export async function nativePosition() {
  if (!isNative()) return null
  try {
    const { Geolocation } = await import('@capacitor/geolocation')
    const p = await Geolocation.getCurrentPosition({ enableHighAccuracy: false, timeout: 10000, maximumAge: 600000 })
    return { lat: p.coords.latitude, lon: p.coords.longitude }
  } catch {
    return null
  }
}

export async function tapHaptic() {
  if (!isNative()) return
  try {
    const { Haptics, ImpactStyle } = await import('@capacitor/haptics')
    await Haptics.impact({ style: ImpactStyle.Light })
  } catch { /* no haptics — fine */ }
}

// Android hardware back: go back in the web history, or leave the app on
// the first screen. Returns an unsubscribe function.
export async function onBackButton(handler) {
  if (!isNative()) return () => {}
  try {
    const { App } = await import('@capacitor/app')
    const sub = await App.addListener('backButton', ({ canGoBack }) => handler({ canGoBack, exit: () => App.exitApp() }))
    return () => sub.remove()
  } catch {
    return () => {}
  }
}
```

In `app/page.js`, delete the local `getCookie` / `setCookie` functions under `// ── Cookie helpers ──` and add `import { getCookie, setCookie } from '@/lib/prefs'` next to the other `@/lib` imports.

- [ ] **Step 1: `AppChrome.jsx`**
```jsx
'use client'

import { useEffect, useState } from 'react'
import Link from 'next/link'
import { usePathname, useRouter } from 'next/navigation'
import { CloudSun, MountainSnow, Menu } from 'lucide-react'
import { t } from '@/lib/i18n'
import { useLang } from '@/lib/useLang'
import { isAppRequest } from '@/lib/app-client'
import { onBackButton, tapHaptic } from '@/lib/native'

const TABS = [['/', 'tabForecast', CloudSun], ['/hike', 'hiking', MountainSnow], ['/more', 'more', Menu]]

// App-only chrome: marks <html data-app> (CSS hides web-only parts and makes
// room for the bar), renders the bottom tab bar and wires Android's back
// button. Renders nothing for web visitors.
export default function AppChrome() {
  const [app, setApp] = useState(false)
  const lang = useLang()
  const path = usePathname()
  const router = useRouter()

  useEffect(() => {
    const inApp = isAppRequest({ userAgent: navigator.userAgent, cookie: document.cookie })
    if (inApp) document.documentElement.dataset.app = '1'
    // eslint-disable-next-line react-hooks/set-state-in-effect -- post-hydration environment sync
    setApp(inApp)
    let off = () => {}
    onBackButton(({ canGoBack, exit }) => (canGoBack ? router.back() : exit())).then(fn => { off = fn })
    return () => off()
  }, [router])

  if (!app) return null
  const active = href => (href === '/' ? path === '/' : path?.startsWith(href))
  return (
    <nav className="app-tabbar fixed bottom-0 inset-x-0 z-40 border-t border-zinc-800 bg-[#0e0e12]/95 backdrop-blur" aria-label={t(lang, 'more')}>
      <div className="max-w-3xl mx-auto grid grid-cols-3">
        {TABS.map(([href, key, Icon]) => (
          <Link key={href} href={href} onClick={() => tapHaptic()}
            className={`flex flex-col items-center gap-1 py-2 text-[11px] ${active(href) ? 'text-emerald-400' : 'text-zinc-500'}`}
            aria-current={active(href) ? 'page' : undefined}>
            <Icon size={20} aria-hidden /> {t(lang, key)}
          </Link>
        ))}
      </div>
    </nav>
  )
}
```

### Task 4: The More screen

**Files:** Create `app/more/page.js` (server: metadata) and `app/more/MoreClient.jsx` (client). Add `/more` to nothing else (not in the sitemap — app screen).

- [ ] **Step 1: `MoreClient.jsx`** — sections: settings (language `<select>` from `LANGUAGES`, unit °C/°F buttons, theme Dark/Light buttons — each writes the same cookie as the home page via `setCookie` and applies it: `metablend_lang` then `location.reload()` for language, `metablend_unit`, `metablend_theme` + `document.documentElement.dataset.theme`), then links (`/leaderboard`, `/heatmap`, `/planner`, `/aviation`, `/privacy`, `/terms`) using existing keys (`leaderboard`, `heatmap`, `planner`, `aviation` with the trailing " →" stripped, `footerPrivacy`, `footerTerms`).
```jsx
'use client'

import { useEffect, useState } from 'react'
import Link from 'next/link'
import { Settings, Compass, ChevronRight } from 'lucide-react'
import { t, LANGUAGES } from '@/lib/i18n'
import { useLang } from '@/lib/useLang'
import { useUnit } from '@/lib/useUnit'
import { getCookie, setCookie } from '@/lib/prefs'
import { SectionTitle } from '../components/ui'

const LINKS = [['/leaderboard', 'leaderboard'], ['/heatmap', 'heatmap'], ['/planner', 'planner'], ['/aviation', 'aviation'], ['/privacy', 'footerPrivacy'], ['/terms', 'footerTerms']]
const label = s => s.replace(/\s*→$/, '')

export default function MoreClient() {
  const lang = useLang()
  const cookieUnit = useUnit()
  const [unit, setUnit] = useState(null)
  const [theme, setTheme] = useState('dark')
  // eslint-disable-next-line react-hooks/set-state-in-effect -- post-hydration cookie sync
  useEffect(() => { setTheme(getCookie('metablend_theme') === 'light' ? 'light' : 'dark') }, [])
  const u = unit ?? cookieUnit

  const pick = (on, text, onClick) => (
    <button onClick={onClick} className={`press flex-1 rounded-lg py-2 text-sm ${on ? 'bg-emerald-400 text-black font-bold' : 'text-zinc-400 hover:text-emerald-400'}`}>{text}</button>
  )
  const row = 'bg-zinc-900 border border-zinc-800 rounded-xl p-4 space-y-2'

  return (
    <div className="space-y-6">
      <h1 className="text-3xl font-bold tracking-tight">{t(lang, 'more')}</h1>
      <section className="space-y-3">
        <SectionTitle icon={Settings}>{t(lang, 'settingsTitle')}</SectionTitle>
        <label className={`${row} block`}>
          <span className="text-zinc-500 text-xs uppercase tracking-wider">{t(lang, 'langLabel')}</span>
          <select value={lang} onChange={e => { setCookie('metablend_lang', e.target.value); location.reload() }}
            className="w-full bg-zinc-800 border border-zinc-700 rounded-lg px-3 py-2 text-sm">
            {LANGUAGES.map(l => <option key={l.code} value={l.code}>{l.label}</option>)}
          </select>
        </label>
        <div className={row}>
          <div className="text-zinc-500 text-xs uppercase tracking-wider">{t(lang, 'unitLabel')}</div>
          <div className="flex gap-1 bg-zinc-800/60 rounded-xl p-1">
            {['C', 'F'].map(x => pick(u === x, `°${x}`, () => { setCookie('metablend_unit', x); setUnit(x) }))}
          </div>
        </div>
        <div className={row}>
          <div className="text-zinc-500 text-xs uppercase tracking-wider">{t(lang, 'themeLabel')}</div>
          <div className="flex gap-1 bg-zinc-800/60 rounded-xl p-1">
            {[['dark', 'themeDarkName'], ['light', 'themeLightName']].map(([x, k]) => pick(theme === x, t(lang, k), () => {
              setCookie('metablend_theme', x); setTheme(x)
              if (x === 'light') document.documentElement.dataset.theme = 'light'
              else delete document.documentElement.dataset.theme
            }))}
          </div>
        </div>
      </section>
      <section className="space-y-3">
        <SectionTitle icon={Compass}>{t(lang, 'moreLinks')}</SectionTitle>
        <ul className="bg-zinc-900 border border-zinc-800 rounded-xl divide-y divide-zinc-800">
          {LINKS.map(([href, key]) => (
            <li key={href}><Link href={href} className="flex items-center justify-between px-4 py-3 text-sm hover:text-emerald-400">{label(t(lang, key))}<ChevronRight size={16} className="text-zinc-600" aria-hidden /></Link></li>
          ))}
        </ul>
      </section>
    </div>
  )
}
```
(The two `pick(...)` maps need `key`s: wrap each returned button in a fragment keyed by `x` — implementer adds `key={x}` to the `<button>` via a third argument.)
